## Documentation scope

Inbox Avenger evolved across multiple prototypes during ACO 494. The academic documents capture the team’s goals, design decisions, testing, limitations, and future direction at the end of the course. Some passages discuss proposed or scaffolded capabilities rather than completed production features. For the current implemented behavior, use the main project README and Version 5.1 notes as the authoritative references.

## Publication boundary

This repository contains public project artifacts only. It does not include real email content, exported user settings, OAuth credentials, private repositories, grades, or student identification numbers.
