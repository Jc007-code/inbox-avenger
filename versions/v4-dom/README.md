# Inbox Avenger Version 4

Version 4 is the advanced DOM-based prototype reconstructed from the project’s original master packet. It adds a larger classification database, stronger important-email detection, cached results, saved filters, a triage queue, and subscription review.

## Install

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked** and choose this folder.
4. Open Gmail and use the popup or injected toolbar.

This historical version reads Gmail’s rendered page structure and stores its working data locally. Gmail interface changes may affect it.
