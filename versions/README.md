# Inbox Avenger version archive

This directory preserves the project’s progression from the first visible Gmail prototype through the final Version 5 build. Each folder is a self-contained unpacked Chrome extension snapshot.

| Project version | Manifest version | Snapshot | Major step |
| --- | ---: | --- | --- |
| Version 1 | 0.1.0 | [`v1-lite`](v1-lite) | Visible Gmail-row scanning, badges, and basic rule-based sorting |
| Version 2 | 0.2.0 | [`v2-adaptive`](v2-adaptive) | Customization, deeper scans, and local adaptive learning |
| Version 3 | 0.3.0 | [`v3-smart`](v3-smart) | Whole-message analysis, popup filters, subscriptions, and unsubscribe discovery |
| Version 4 | 0.4.0 | [`v4-dom`](v4-dom) | Larger word database, cached review, triage queue, saved filters, and subscription review |
| Version 5 API-ready | 0.5.0 | [`v5-api-ready`](v5-api-ready) | Gmail API scaffolding, mailbox indexing, labels, search, and OAuth architecture |
| Version 5 final | 5.1.0 | [`v5-final`](v5-final) | Rules plus local ML, demo mode, scheduled scanning, Gmail API path, history, and safer defaults |

The maintained portfolio version is also kept at the repository root. Historical snapshots are preserved for learning and comparison; they may rely on older Gmail page structures and should not be treated as production email-security software.
